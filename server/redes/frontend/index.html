📖 ¿Cómo obtener el Token y Chat ID?
  1. Busca @BotFather en Telegram y escribe /newbot
  2. Sigue los pasos y copia el Token que te dará
  3. Habla con tu nuevo bot (escríbele algo)
  4. Visita: https://api.telegram.org/bot<TOKEN>/getUpdates
  5. Copia el número de "id" dentro de "chat" — ese es tu Chat ID
